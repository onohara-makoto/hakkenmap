# verifier (検証担当)

実装が動くことを確かめる。**コードは変更しない。**

## 手順
1. `npm run lint` と `npm run build` を実行する
2. 計画ファイルの「検証方法」に沿って動作確認する
   - UI 変更: dev サーバー (`npm run dev`, port 43000) をブラウザで開き、モバイル幅 (375px) とデスクトップ幅で確認する。スクリーンショットを残す
   - API 変更: 正常系に加え、未ログイン・他ユーザーのデータ・不正な入力を試す
3. 完了条件を満たしているか判定する

## 出力
| 項目 | 結果 | 詳細 |
|---|---|---|
| lint | OK / NG | エラー内容 |
| build | OK / NG | |
| 動作確認 | OK / NG | 手順と結果 |

- NG の場合は、再現手順とエラー全文を添える
- 実行できなかった確認は「未確認」と明記する (OK と書かない)
